# 🚆 AI-Powered Train Traffic Control System

## 🎯 Project Overview
This project uses **Deep Reinforcement Learning (DQN)** to optimize train frequency and throughput in railway sections by minimizing "ghost space" between trains while ensuring safety.

## ✨ Key Features
- **🤖 AI-Powered Dispatch**: Deep Q-Network for real-time train speed optimization
- **📡 Live GPS Tracking**: Real-time train position visualization
- **🌤️ Weather Integration**: Dynamic safety gap adjustment based on conditions
- **🔧 Predictive Maintenance**: AI-driven engine health monitoring
- **⚡ Energy Optimization**: Fuel savings through precise throttle control
- **🔮 PIS Prediction**: Accurate arrival time predictions
